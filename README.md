# The Chronicle of Azad Nishad - Ancient Book Portfolio

An immersive, ancient manuscript-themed portfolio website that presents professional experience and skills in the style of a medieval chronicle.

🌐 **Live Site**: [araom.me](https://araom.me) | [AzadNishad.github.io](https://azadnishad.github.io)

## ✨ Features

- **Ancient Book Design**: Leather-bound cover with embossed gold lettering
- **Parchment Pages**: Aged paper texture with vintage typography
- **Interactive Navigation**: Page-turning system with keyboard support
- **Medieval Aesthetic**: Ornamental decorations and illuminated letters
- **Responsive**: Fully responsive across all devices
- **Immersive Experience**: Old English writing style throughout

## 🎨 Design Philosophy

The portfolio is designed as an ancient chronicle or medieval manuscript, creating a unique and memorable browsing experience. Each section is presented as a chapter in the book.

## 🎭 The Four Chapters

1. **Chapter I - The Author's Tale**: Personal introduction and achievements
2. **Chapter II - The Arts & Crafts**: Technical skills organized by category
3. **Chapter III - The Grand Works**: Featured projects and accomplishments  
4. **Chapter IV - Send Word**: Contact form and social connections

## 🔧 Technologies Used

- HTML5, CSS3, Vanilla JavaScript
- Google Fonts (Cinzel, Crimson Text, IM Fell English)
- Font Awesome Icons
